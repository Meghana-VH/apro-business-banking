# Apro Business Banking

A premium business banking landing page inspired by the supplied Apro reference: checking accounts, corporate cards, treasury and spend controls.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

This is a standalone React + Vite frontend project. No backend or API keys are required.
